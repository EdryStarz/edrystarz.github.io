About the project

A focused Tkinter utility with increment, decrement, manual values and always-on-top mode. Atomic writes preserve the current value between sessions.

  • Buttons, arrow keys and manual integer input
  • Always-on-top mode and reset confirmation
  • Persistence and malformed-data fallback verified
