Ashen Oath

An offline Android habit planner with pixel-art battles, equipment and local save backups.

Download Android APK ↗Game website and source links ↗
OVERVIEW

About the project

Mark self-reported habits to earn experience and prepare a hero for three forest opponents. A signed Android 0.7.2 APK and source are public. Release documentation records emulator checks for 0.7.1 and asset/signature checks for 0.7.2; physical-device performance was not profiled.

  • Scheduled habits, rest days and a progress journal
  • Hero progression, equipment and tactical battles
  • JSON save export/import; no account required
TECHNOLOGY

Godot · GDScript · Android

AVAILABILITY
Russian game interface. Android 7.0+, ARM64 / x86_64. APK release available; store approval not verified. No browser game demo. Export saves before replacing a debug build.
