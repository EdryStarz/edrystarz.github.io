WHAT IT DOES

A closer look.

An unofficial extension displaying records from Stars About War. Labels link to the source so you can review its reasoning. Classifications belong to the source; this extension is not an independent fact-checker.

  • Labels across YouTube feeds, search results and channel pages
  • Local channel matching and scheduled feed updates
  • Cached fallback data and Ukrainian / Russian localization

JavaScript · Manifest V3 · Chrome APIs

Published in Chrome Web Store. Store version and availability can change.
