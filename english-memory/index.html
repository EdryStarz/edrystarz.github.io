WHAT IT DOES

A closer look.

A native Windows application using local Whisper transcription and language-model analysis. Your vocabulary lives in SQLite on your device. Model-generated translations and level labels need human review.

  • Microphone / PC audio capture with explicit start and pause
  • Local vocabulary, subtitle imports and review scheduling
  • Windows x64 build verified; 74 default behavior checks passed

C# · .NET 10 · WinUI 3 · Whisper · SQLite

Windows 11 x64. Requires building from source and downloading models. No installer is hosted here.
