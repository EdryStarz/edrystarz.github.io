WHAT IT DOES

A closer look.

A Python backend and React interface for local media processing. Completed pipeline stages can be reused. The frontend build was checked; a full Docker/media processing run was not verified in this portfolio review.

  • Local faster-whisper transcription and scene analysis
  • Vertical reframing, subtitles and FFmpeg export
  • Stage persistence and optional publishing connectors

Python · FastAPI · React · FFmpeg

In development. External publishing requires configuration and is disabled by default.
