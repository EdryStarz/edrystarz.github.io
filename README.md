# EdryStarz project collection

Public project showcase with individual landing pages, installation/setup links,
project maturity labels, share buttons and social preview images.

Live site: https://edrystarz.github.io/

Static HTML, CSS and JavaScript. No accounts, tracking pixels or analytics.
GitHub Pages serves the committed files from `main`. `.nojekyll` disables Jekyll.

To change content, edit `PROJECTS` in `build.py`, install Pillow and run
`python build.py`. The generated files are committed; visitors and hosting do
not need Python. Typographic preview cards are promotional graphics, not product
screenshots. They make no claims about usage, ratings or deployment performance.

Project source code stays in the linked repositories. The extension pages link
to their published store listings. See `LAUNCH-KIT.md` for ready-to-edit launch
copy; nothing is posted automatically.
