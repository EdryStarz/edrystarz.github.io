OVERVIEW

About the project

A standalone Node.js collector run by GitHub Actions. A private server supplies authorized due feeds and validates persisted results. The public repository contains transport code, not the CrimeWeb map, database, classifier or geolocation implementation. Recent workflow runs succeeded; they do not independently verify reported events.

  • Interleaved regional feed queues and resumable maintenance requests
  • Bounded public HTTP fetching with redirect and address checks
  • Aggregate operational reporting without article bodies
TECHNOLOGY

Node.js · JavaScript · RSS · GitHub Actions

AVAILABILITY
Beta integration requiring a compatible private server and scoped credential. No standalone map demo or packaged release. Scheduled runs are best effort; news reports are not verified facts or crime-rate comparisons.
