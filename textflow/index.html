About the project

A portable Windows utility for Unicode text snippets, shortcuts and QuickTextPaste imports. Paste requests are serialized; the inserted text remains on the clipboard.

  • Global hotkeys and a searchable snippet palette
  • Portable JSON storage and Win32 input integration
  • Nine behavior checks passed on Windows
