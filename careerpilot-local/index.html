OVERVIEW

About the project

A Python public preview extending fikstt2/hh-ai-agent. Searches public job boards and configured ATS/Telegram sources. Supported submissions require explicit configuration; unknown forms, login and missing required facts can need human review. Successful CI does not prove live compatibility with every employer website.

  • CV import and local Ollama inference
  • Dry-run discovery with sending disabled by default
  • Private application ledger and supported opt-in form routes
TECHNOLOGY

Python · Playwright · Ollama · Telegram

AVAILABILITY
Public preview v0.2.0; not a hosted application or universal unattended applicant. Requires local setup and personal credentials. Based on an upstream MIT project.
