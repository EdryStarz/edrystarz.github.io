OVERVIEW

About the project

A browser extension showing channel-level labels based on gubanovfiles.com. A label refers to the channel record, not necessarily the video you are watching. Review the original evidence before drawing conclusions.

  • Local matching by channel ID, handle or unique name
  • Background database updates with a cached fallback
  • Available for Chrome and Firefox
TECHNOLOGY

JavaScript · WebExtensions · HTML / CSS

AVAILABILITY
Published browser extension. Source records are maintained by gubanovfiles.com.
