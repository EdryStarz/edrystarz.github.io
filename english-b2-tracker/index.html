WHAT IT DOES

A closer look.

A local-first study planner built with Next.js and IndexedDB. It organizes practice and records progress; it does not certify B2 proficiency. Export JSON backups before clearing browser data.

  • Daily tasks, weekly reflections and a study calendar
  • Vocabulary practice, focus timer and error log
  • Production build, lint and TypeScript checks passed

TypeScript · React · Next.js · IndexedDB

This page introduces the project. It is not a hosted tracker demo. Initial sample entries are examples.
