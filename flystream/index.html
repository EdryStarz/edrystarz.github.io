About the project

A React and Three.js prototype combining shared streamer state with a scientific anatomy workbench. Demo mode works without provider credentials. Real KICK integration and external broadcasting remain unverified.

  • Moderated chat, polls and two scored games
  • Rights-gated local media and video-only vertical WebM export
  • Local verification documented; clean-install CI currently fails
